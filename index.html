Hello

I make software that
doesn’t feel like software.

I’m a developer and designer working somewhere between research tooling and interaction design. I like problems where the interface is the argument — where how something moves changes what it means.

Recent work spans a rethinking of economic indicators, a three-thousand-year-old divination system rebuilt for the browser, and whatever I’m tinkering with this week.
